# AI Agent 项目投递展示页设计

日期：2026-08-31

## 目标

为简历投递制作一份无需讲解也能独立成立的单页项目展示。招聘方应能在 60–90 秒内理解候选人的定位、三个项目解决的问题、候选人与 AI Agent 的分工，以及可核验结果。

## 受众

- AI 产品经理、Agent 产品经理、AI 应用工程等岗位的招聘方；
- 首轮筛选人员可能只快速浏览，不假设其会听候选人口头讲解；
- 页面需要兼顾普通浏览器查看和打印为 PDF。

## 核心叙事

主定位：

“我负责定义真实问题、领域边界与验收标准；AI Agent 放大研究和工程执行力；最终用测试、溯源与真实反馈验证结果。”

三个案例：

1. 用工合规智能系统：复杂企业业务与高风险领域的端到端 Agent 工作流；
2. MockInterview：通过真实试用纠正初始 RAG 产品方向的语音 Agent；
3. Career Pathfinder：有证据、可反证、保护隐私的职业决策 Agent。

## 页面结构

### 1. 首屏

- 姓名以“AI Agent 项目案例集”替代，避免未经确认展示个人敏感信息；
- 一句定位；
- 三个快速指标：3 个真实场景、跨业务/语音/决策三类 Agent、全部具备验证证据；
- “查看项目”锚点按钮；
- 右侧或下方为三项目简洁索引，不使用装饰性人物插画。

### 2. 项目总览

三张摘要卡展示：

- 项目名称和一句话价值；
- 服务对象；
- 最关键结果；
- 能力标签；
- 点击或键盘操作切换到对应案例。

### 3. STAR 案例

每个项目使用相同结构，便于快速比较：

- Situation：真实问题、受益对象和为什么值得解决；
- Task：候选人承担的目标、约束和验收责任；
- Action：关键产品/工程动作；
- Result：量化成果、本轮验证和未完成边界。

Action 中必须单列：

- 我负责：问题定义、领域材料、产品判断、验收和真实反馈；
- AI Agent 负责：研究、任务拆解、编码、测试、批处理和文档化；
- 共同闭环：一次最能体现反馈驱动改进的事件。

### 4. 模型与工具选择

每个案例只列与决策有关的工具，不做技术名词堆砌：

- 用工合规：Codex gpt-5.5、DeepSeek v4 Flash、WeKnora、Go/Vue/PostgreSQL、RAG/trace；
- MockInterview：Codex gpt-5.6-sol、DeepSeek v4 Flash、LangGraph、FunASR、Edge TTS、SQLite/Chroma；
- Career Pathfinder：Codex gpt-5.6-sol、模块化 skill、RED/GREEN 行为测试、独立审查。

每项工具附一行“为什么选择”，并明确用工合规运行时底层 LLM 未被证据确认。

### 5. 结尾

- 三项能力总结：领域抽象、Agent 工作流设计、真实反馈验证；
- 一段可复制到简历的三项目精简描述；
- 不添加未经用户确认的电话、邮箱、公司或学校信息。

## 视觉设计

- 方向：克制、可信、偏研究型产品案例，不使用渐变大标题或模板化科技光效；
- 配色：深墨蓝主色、暖白背景，三个项目使用低饱和青、橙、紫作为识别色；
- 字体：系统中文无衬线，数字使用等宽或紧凑字形；
- 卡片：小圆角、细边框、轻阴影；强调证据而不是装饰；
- 信息密度：桌面双栏，移动端单栏；正文最小 15px；
- 动效：仅使用轻微切换和进入效果，并尊重 prefers-reduced-motion。

## 交互

- 顶部项目导航与正文锚点同步；
- 支持鼠标、键盘和触屏；
- 每个项目默认展示完整 STAR，不依赖悬浮才能读到内容；
- “复制简历描述”按钮复制纯文本；
- “打印 / 保存 PDF”按钮调用浏览器打印；
- 不使用后端、账号、外部 API 或持久化数据。

## 技术方案

- 目标仓库：`https://github.com/Maayut/Personal-Resume`；当前为公开空仓库；
- 本地实施目录：`work/Personal-Resume`；
- 新建单路由静态展示站；
- 使用 Sites 默认前端框架和 shadcn 基础组件；
- 项目内容作为本地结构化数据，页面组件循环渲染；
- 使用共享主题变量控制颜色、间距与排版；
- 添加打印样式，隐藏导航按钮并保证项目卡不被跨页切断；
- 默认不引入图片，使用排版、数字、标签和简单功能性图标完成信息表达。

## 验收标准

1. 首屏无需滚动即可看懂候选人定位和三项目范围；
2. 三个案例均含 Situation、Task、Action、Result；
3. 三个案例均说明模型/工具、选择原因、人机分工、挑战方案、结果与诚实边界；
4. 页面在桌面和手机宽度下无横向溢出；
5. 键盘可访问项目导航和复制/打印按钮；
6. 复制按钮能输出干净的简历文本；
7. 浏览器打印预览内容完整、无交互控件；
8. 最终构建成功，无 TODO、TBD、个人隐私或未经证实的模型归属。

## 范围外

- 不提供登录、后台编辑、在线数据库；
- 不嵌入三个原项目的实时运行环境；
- 不制作复杂视频、3D 或装饰性 AI 图片；
- 不承诺未经验证的商业效果或用户规模；
- 不把“95% 画像把握”解释成统计准确率。
