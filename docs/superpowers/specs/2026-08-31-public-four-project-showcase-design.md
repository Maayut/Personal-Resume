# 公开四项目展示站改版规格

## 目标

把现有 AI Agent 项目案例站升级为任何人无需登录即可访问的公开作品集，并新增经过本地代码与 Codex 历史核验的“FillResume｜智能网申助手”案例。删除面向复制粘贴的“可直接放进简历的项目描述”板块，让页面只承担招聘方快速浏览与证据展示。

## 内容结构

- 首屏改为“四个真实问题、四种 Agent 实践”，保留证据优先的定位。
- 项目索引从三列升级为自适应四卡布局。
- 四个案例都使用同一 STAR、人员分工、工具选择、协作闭环和诚实边界结构。
- 新案例标题为“FillResume｜智能网申助手”，强调个人秋招痛点、AI 协作、隐私优先和人工最终提交。
- 删除 `resumeCopy` 数据、复制按钮、打印按钮和整段简历文案区。

## 智能网申助手案例证据边界

- Situation：个人秋招需要在不同招聘系统重复填写同一份教育、实习与项目资料，手工复制耗时且容易漏填、错填。
- Task：从真实投递流程出发调研招聘页面的表单差异，借助 AI Agent 实现本地优先的 Chrome MV3 自动填表与投递留痕工具。
- Action：梳理个人使用场景、调研原生表单与受控组件、设计确定性字段分类器与事件写入，并用 TDD 和真实 Chrome E2E 验证。
- Result：42/42 单元测试、生产构建、独立 Chrome E2E 与代码审查均有历史记录；E2E 覆盖保存资料、填写表单、不自动提交和生成一条投递记录。
- Boundary：系统以确定性规则覆盖常见表单，不宣称兼容所有招聘网站；复杂自研控件仍可能需要人工处理，并且始终不会自动提交。

## 视觉方向

采用“Editorial Evidence Dossier / 高级研究档案”风格：暖纸色为主背景，深墨蓝为主色，四个项目分别使用青绿、橙、紫灰和钴蓝强调色。标题使用宋体/衬线展示字体，正文使用现代中文无衬线字体；大字号标题、细线网格、档案编号、非对称留白和分层纸张阴影共同形成识别度。

## 动效

- 首屏标题、说明与证据面板按顺序淡入并轻微上移。
- 项目索引和正文块在进入视口时揭示。
- 顶部提供细线滚动进度条。
- 项目卡片在指针移动时出现低强度光泽，悬停时轻微抬升。
- 动效只使用渐变、透明度和 transform；`prefers-reduced-motion` 下全部降级为静态。
- 页面无 JavaScript 时内容仍完整可见。

## 技术方案

- 保持 React、vinext、TypeScript 与现有单页结构。
- 通过服务端输出的渐进增强脚本实现 IntersectionObserver、滚动进度和指针光泽，不引入新的客户端 React 水合边界。
- 内容合同测试验证四个项目、必备字段和证据边界；界面合同测试验证简历区移除和动效降级。
- 构建成功后推送 GitHub，将现有 Sites 权限改为 public，保存并公开部署新版本。

## 验收标准

1. 页面展示且只展示四个目标项目。
2. 页面不存在“可直接放进简历的项目描述”、复制或打印动作。
3. 智能网申助手案例包含完整 STAR、工具选择、人机分工、结果和诚实边界。
4. 首屏、索引、滚动揭示和悬停效果形成统一高级视觉，移动端与减少动态效果模式可用。
5. 所有测试和生产构建通过。
6. 最终 URL 在未登录 ChatGPT 的情况下可公开访问。
